MATH LANDING ASSESSMENT - DEPLOYMENT

Open index.html to run the complete assessment. For deployment, upload this
whole folder and preserve its structure. index.html uses the adjacent
JavaScript/CSS files, assets/ folder and vendor/ folder.
assets/ includes the pictures and fonts; vendor/ includes reused libraries.

standalone.html is an additional self-contained copy with scripts, fonts,
pictures and catalogue downloads embedded. It can also run by itself.

Excite and Inspire each have Parts 1-4. Parts 1-3 retain 12 questions each.
Part 4 starts with the three newly requested questions for each grade.
The PDF catalogues, sample parent report, teacher guide and page-code lists
are supplied here as separate reference files. Actual student reports are
downloaded from the assessment after the teacher opens results.

This folder is supplied unzipped. Preserve browser data and export a backup
before switching browsers or devices. The sample report is demonstration
data; it is not a real student report.
